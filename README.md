## How figures are sourced

Every number in a video and in a spreadsheet is read on the page of the agency
that issues the rule — the IRS, the CFPB, the SSA, the Department of Labor, the
Federal Reserve. Never from a blog, a news site, another video, or an AI.

Secondary sources are fine for understanding something. They are never used to
establish a figure, because they copy each other and an error spreads fast.

## Figures change every year

Tax figures are dated. A file named `-2026` holds 2026 rules and becomes wrong
on January 1st. When a year rolls over, a new file is published next to the old
one — the old one is never overwritten, because someone may have been using it
for months.
